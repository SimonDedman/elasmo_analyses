Fisheries: choose how you want to review

Every option judges the same question, "of every paper we hold, which are genuinely about this concept?", and every one of them records your answers the same way. They differ only in how much the page shows you and how much it asks for. Pick whichever suits how you work; you can switch at any time and your answers follow you.

Grouped by what you are doing, most useful first within each group. recommended where we would start time per 50 papers

Family 1 Judging papers

The core job: say whether each paper really belongs to the concept. Start here.

1A
One paper at a time A card per paper, closest to the borderline first, with the quotations and every keyword the rule looked for. The machine's own verdict is hidden. You do: read, then press I, O or U. Nothing else.
recommended~20 minno trainingkeyboard only
1B
One paper at a time, with the score shown The same cards, but you can see the score, how the rule voted, and whether the card is a borderline case or a spot check. You do: the same, with the option to disagree with the rule deliberately.
~20 minno training
1C
The whole list at once Every paper ordered by score with the qualifying line drawn in, so you can see the shape of the problem and work outwards from the line. You do: drag or shift-click a run of papers and judge them together.
~8 minfastesteasy to over-claim

Family 2 Improving the rule

For the concept's champion, once some papers are judged: change the rule and watch what it does to the list.

2A
Edit the rule Keywords, how much a mention counts in each part of a paper, the score needed, and the anchor words. The line moves as you type. You do: drop a keyword that misfires, or adjust the bar, and see which papers cross.
for championsopen-ended
2B
See what an edit changes One worked example: the bar raised by one and a misfiring keyword dropped. The list filters to exactly the papers that move. You do: nothing. This is the one to look at before you touch anything.
~3 minread only
2C
Let the search fit the rule Instead of anyone tuning numbers, a search finds the rule that best reproduces the judgements, and reports how it does on papers held back from the fitting. You do: judge papers first; then read the proposal and accept or reject it.
~5 minneeds ~30 judged

Family 3 Checking each other

Two people on one concept, and concepts that have never been run.

3A
Compare two reviewers Export your answers, load someone else's, and filter to the papers where you disagree. You do: discuss only the conflicts, which are usually where the concept's edge really is.
~10 minsecond pass
3B
Try a concept we have never run David's proposed "Capture: CPUE" wording, scored across the corpus for the first time, beside the live column it would replace. You do: judge whether the set of papers it picks is what the concept should mean.
~15 minnew concepts
